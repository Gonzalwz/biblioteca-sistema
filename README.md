# Sistema de Biblioteca

Proyecto de gestión de biblioteca desarrollado en PHP y MySQL.

Existe una versión API REST de este sistema, hecha con Laravel y Sanctum sobre la misma base de datos: [biblioteca-api](https://github.com/Gonzalwz/biblioteca-api).

## Funcionalidades

- Gestión de autores, editoriales y libros
- Registro de estudiantes
- Control de préstamos y devoluciones
